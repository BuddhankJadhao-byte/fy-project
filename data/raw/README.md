# Raw dataset

The original dataset is supplied as an Excel workbook:

- [`godishala_substation_2021.xlsx`](godishala_substation_2021.xlsx) — original binary workbook
- [`godishala_substation_2021.csv`](godishala_substation_2021.csv) — UTF-8 text copy for viewing directly in GitHub or a text editor

Both files contain the same 8,760 hourly source rows. The CSV is provided only
for easier viewing; the data-preparation pipeline continues to use the original
workbook.

For the cleaned, model-ready columns, see
[`../processed/godishala_microgrid_hourly_2021.csv`](../processed/godishala_microgrid_hourly_2021.csv).
